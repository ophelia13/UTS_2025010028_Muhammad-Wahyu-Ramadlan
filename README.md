## 📌 Deskripsi Proyek
Website kedai kopi ini dirancang untuk menampilkan menu kekinian yang menargetkan kalangan Gen Z. Website ini mengimplementasikan prinsip-prinsip desain web dasar sesuai dengan instruksi tugas UTS, termasuk penerapan *Semantic HTML*, *Box Model*, dan *CSS Layouting* (Flexbox/Grid).

## ✨ Fitur & Komponen Sesuai Ketentuan
1. **Header & Navigation Bar:** Terdapat logo dan navigasi utama.
2. **Hero Section:** Area sambutan utama untuk pengunjung.
3. **Katalog Menu (Minimal 5 Kartu):** Menampilkan 5 menu kopi kekinian:
   - Butterscotch Sea Salt Latte
   - Strawberry Matcha Latte
   - Berry Coffee Mocktail
   - Earl Grey Cloud Tea
   - Nutella Croffle
4. **Formulir Kontak / Reservasi:** Form fungsional secara visual untuk reservasi meja.
5. **Footer:** Memuat informasi hak cipta dan operasional kedai.
